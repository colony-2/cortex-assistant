# Cortex Assistant

Own the browser-independent assistant policy, versioned Go facade and cell-local c2j session recipe. Execute durable contextual review/story/global discussions as ordinary jobs in the configured root and tenant. Capture bounded authorized context and present the actual recorded inputs, task results, human receipts and artifact references as a transient conversation view. Do not maintain a second transcript, context artifact, message ledger, session database or provider session.

Own model adaptation, per-response document materialization, authorized file/image/video/audio downloads, session discovery, prompt-input finish and reopening at the last actual prompt scope. Existing-cell goal creation requires current human confirmation of the exact canonical target and prompt; ordinary frozen submissions deduplicate retries. Preserve logical identity and recorded ancestry across executions without worker workspace or cache dependence.

Cortex owns UI, trusted identity binding and a simple REST adapter that delegates assistant policy. c2j owns execution/input/replay/restart; existing JobDB storage owns retention; c2ops owns model operations. Root owns cell eligibility and creation approval. This cell does not own arbitrary editing, shell execution, repository creation, compute dispatch, a new authentication system or a replacement workflow runtime.
